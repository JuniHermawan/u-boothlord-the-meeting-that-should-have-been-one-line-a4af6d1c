A tiny Python program that writes the single sentence that could have replaced an entire pointless meeting to /output/entry.txt: yesterday's email already decided it, so the meeting is just the reply-all thread with chairs.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/meeting-out python3 main.py && cat /tmp/meeting-out/entry.txt
```
